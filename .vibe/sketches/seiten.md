# Skizzen der Seiten (Ablauf, was Lernende sehen)

Jede Seite: Titel, Ziel-Satz, Abschnitte `einstieg` → `idee` → `beispiel` → `uebung`, am Ende „Weiter“ zur nächsten
Station. Bei 360 px alles einspaltig; Tabellen höchstens 3 Spalten.

1. **alltag/informatiksysteme** – Bild Ausstellung (Jona, Selin, drei Tische) → erste Frage (Fahrrad, Smartwatch,
   Lineal) → Merkmal „kleiner Computer mit Programm“ (definition) → Merke „Strom allein reicht nicht, Bildschirm ist
   kein Muss“ → Anleitung Gerätesuche → Übungen: Mehrfachauswahl, wahr/falsch, Zuordnen, generierte Ja/Nein-Aufgabe.
2. **alltag/hardware-software** – Frage „Was kannst du anfassen?“ → Bild Tablet mit Teilen und App-Wolke → Begriffe
   Hardware, Software → Beispielkasten Kamera + Kamera-App → Übungen: generiert Hardware/Software, Zuordnen Hardware →
   Software, Einzelauswahl Tablet ohne Software.
3. **alltag/programme-bedienen** – Frage „Selins Bild ist weg“ → Malprogramm-Fenster mit Markern 1-6 → Tabelle Befehl |
   Was passiert | Tastenkürzel → Merke Zwischenablage → Übungen: Reihenfolge, Zuordnen Befehl → Wirkung, generiert
   „Wie viele Sonnen?“.
4. **innen/bestandteile** – Frage „Wo denkt das Tablet?“ → gläserner Computer mit Markern → Tabelle Bauteil | Aufgabe |
   Vergleich (Schreibtisch = Arbeitsspeicher, Schrank = Festspeicher; wo der Vergleich aufhört) → Merke „ohne Strom
   vergisst der Arbeitsspeicher“ → Übungen: Marker zuordnen, Bauteil → Aufgabe, Einzelauswahl Stromausfall, wahr/falsch
   Akku.
5. **innen/eva-prinzip** (Muster) – Frage „Jona tippt 3 + 4“ → Bild EVA-Kästen mit Schublade → definition EVA-Prinzip,
   Zeile EVAS → Anleitung Rollenspiel „Wir sind ein Computer“ → Übungen: EvaSortierer (siehe eva-sortierer.svg),
   generiert Vorgang ordnen, Einzelauswahl Touchscreen, Mehrfachauswahl Ausgabegeräte.
6. **innen/geraet-auswaehlen** – Frage „Mia will ein Referat schreiben“ → Tabelle Gerät | Eingabe | Ausgabe → Kasten
   „Drei Fragen“ (Was soll herauskommen? Was gebe ich ein? Welches Gerät und Programm kann das?) mit EVA-Bild →
   Übungen: generiert Aufgabe → Gerät, Zuordnen Aufgabe → Programmart, Einzelauswahl Begründung, wahr/falsch „das
   neueste“ → Rückblick auf alle Stationen.
